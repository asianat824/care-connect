# Refine the caregiving experience

## What will change
- Keep the existing warm cream, plum, sage, coral, serif-led visual identity while improving text and control contrast.
- Make capacity choices wrap safely, and add clear low/full labels plus an accessible name to the energy slider.
- Clarify each person card’s “What matters” content and consistently identify direct contributions as “Shared by [name].”
- Update the invitation action and reshape My Voice into one simple contribution screen with the six requested prompts and a clear audience explanation.
- Reduce Care Circle’s primary tabs to Members, Requests, Updates, and Handoffs; combine offers with Requests and place resources/community below the main tab content.
- Add a person filter to Care Moments when needed, rename the weekly-prompt action, and show a growing fictional memory collection below the form.

## Technical details
- Preserve the existing local saved-state model and five-item navigation.
- Reuse the existing routes and shared controls; My Voice remains reachable only from a person profile.
- Keep all requested interactions keyboard accessible and prevent controls from causing page-level horizontal overflow.
- Verify desktop and mobile rendering, interactions, accessibility labels, and the preview build.
